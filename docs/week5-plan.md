## 2. L1 真实模型实验与 L2 人工审核

- 配置 DeepSeek 或通义千问，选择 10–20 个问题，固定检索和回答配置。
- 分别运行缓存关闭、缓存预填充和开启第二遍，记录 P50/P95、首字时间、模型调用和 token 用量。
- 重复问题实验的命中率反映工作负载构造，简历使用响应时间和模型调用、token 节省数据。
- 2026-11-13 已完成 12 题 DeepSeek Flash 真实对照，结果及限制见 [API 报告](../eval/results/week5/README.md)。
- 用户逐条审核 L2 的 50 条记录，确认可复用关系后更新 `human_reviewed`，用冻结向量重新扫描。
- L2 对外报告错误数与接受数，当前待审试验结果为测试集 1/7。

## 3. rerank 实验

- 在开发集固定检索设置，比较 rerank 配置和召回、排名、耗时。
- 配置锁定后，对 20 题冻结留出集验证一次。当前留出集 D 的 Recall@5 为 67.5%。
- Week 4 三阶段关闭缓存均与 Week 3 D 的 60 题结果逐题一致，检索行为已由回归覆盖，因此该缓存里程碑保留留出集，待本阶段使用。
