# 简历项目条目

## 复杂文档 RAG 工程优化，MaxKB 二次开发

- 集成 MinerU 独立解析服务，实现可配置路由、预览占位与异步构建两阶段流程、内容哈希解析缓存，扫描件类问题 Recall@5 从 0/10 提升至 9/10，扫描件上传占位响应约 0.44 s。
- 通过消融实验定位子块向量缺少标题上下文的问题，实现标题前缀与表格感知切分，开发集 Recall@5 从 81.67% 提升至 89.17%，20 题冻结留出集从 45.0% 提升至 67.5%，同时修复关键词索引与子块错位问题。
- 设计模型实例指纹与输入文本哈希驱动的 PG、Redis 向量缓存，热重建业务模型调用从 102 次降至 0，向量化阶段耗时从 50.13 s 降至 0.45 s，总耗时从 57.53 s 降至 9.83 s，60 题检索结果逐题一致。
- 实现 L1 精确问答缓存，在向量存储层通过版本递增统一失效，并完成权限、引用、并发锁及流式响应验收。在 12 题 DeepSeek Flash API 单轮对照中，命中后的响应 P50 从 1.243 s 降至 27.0 ms，模型调用从 12 次降至 0，关闭组对应 token 用量为 24751。另设计 L2 的对象、数字、限定词与证据一致性复核方案。

## 使用口径

向量缓存数字来自本地 CPU `local_model` 单次实测。上传响应的同步解析参考约 57 s，异步占位约 0.44 s。留出集是同语料的新问题，作者先验与题型分布说明见原报告。

L1 真实对照使用重复问题和固定配置，回答质量单独待复核，详细口径见 [API 实验报告](../eval/results/week5/README.md)。离线夹具延迟保留为协议验收数据。L2 的 1/7 结果保留待人工审核标签状态，对外数值引用在人工确认后更新。

原始证据见 [第 2 周报告](week2-report.md)、[分块消融](../eval/results/week3/README.md)、[留出集](../eval/results/week3/holdout/README.md) 和 [第 4 周报告](../eval/results/week4/README.md)。
