# 公开制度扫描件演示

本目录提供中卫市人民政府网站公开的《信息安全管理制度》原件及栅格化扫描版本，来源、哈希与生成参数记录于 `manifest.json`。原发布文件保留其原有权利归属，内容用于解析与检索演示，原件可从发布网站核验。 [原始公开文件](https://www.nxzw.gov.cn/zwgk/bmxxgkml/swsjkwyh/fdzdgknr_49861/wsyl_49877/201811/P020181121330110409821.pdf)

- `security-policy-original.pdf` 为公开原件，保留文字层，用于核验扫描结果。
- `security-policy-scan.pdf` 复用项目已有的受控扫描样本，共七页，无文字层，按最长边目标 1800 像素栅格化。原页顺序与原件一致，生成记录见 `services/mineru/samples/business_policy_scan.provenance.json`。
- 导入脚本只索引扫描版本，以便从回答引用中核验扫描件解析链路。
- `questions.json` 包含演示问题及用于自动验收的关键短语。

## 一条命令导入

完成根目录 README 的启动步骤，并在 `.env` 配置有效回答模型后运行。

```bash
docker compose run --rm demo-import
```

脚本通过管理 HTTP API 创建专用示例知识库、上传原始扫描 PDF、保存预览并等待解析与向量化完成，再配置专用回答模型、创建及发布应用。发布后核对知识库绑定，开启来源展示，经过公开聊天 HTTP API 提问，并检查回答内容与扫描文档引用。

示例问题为“中卫市卫生和计划生育局公开的信息安全管理制度采用什么责任原则？”，预期回答包含“谁主管”和“谁负责”。完成后终端输出聊天链接及回答，核验记录保存于 MaxKB 数据卷的 `/opt/maxkb/demo/state.json`。

同一数据卷中的导入命令使用文件锁串行执行。重跑会按专用资源名称恢复已有知识库和文档，并更新示例模型与应用配置。已有解析或向量化失败会明确退出，需要先在管理端处理对应失败任务。导入会调用配置的真实回答 API，凭据通过 MaxKB 标准模型接口加密保存。
