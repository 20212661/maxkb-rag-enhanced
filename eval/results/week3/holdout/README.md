## 作者与冻结过程

新题依据原始资料编写，扫描、图片及表格关键句通过原页核验，事实和跨段落证据核对了 PDF 文本层或 Word XML。写题阶段读取原始资料，随后使用旧题文本做重复检查。作者此前已经接触本对话中的旧失败分析和消融结果，这一点记录在 freeze.json。

初稿完成后进行独立的重复检查，检查规范化问题文本和同文档标准句的包含关系。h007、h017 与旧标准句重叠，已在首次留出检索前换成新的标准编号事实和资产审核事实。最终 20 题没有完全相同的问题或同文档标准句包含重叠，近似文本检查阈值为 0.65。该检查覆盖字符串层面的重复。
