# Week 4 缓存验收

## 向量缓存

2026-11-13 使用本地 `local_model` 服务的 `text2vec-base-chinese` CPU 模型，向量维度 768。冷缓存指 PG 文档向量缓存清空，模型权重已在前置准备时加载。冷、热重建均以 eager Celery 调用正常知识库重建任务。

实验复用 Week 3 D 的 103 个冻结父段落，重新生成 273 条子块向量。保留原图片引用，段落 limit 为 1200，标题前缀和表格切分均开启。

### 简历表述

> 设计基于模型实例指纹与实际输入文本哈希的向量缓存，使用 PostgreSQL 持久化文档向量、Redis 缓存查询向量。在本地 CPU 模型实验中，热重建业务模型调用从 102 次降至 0，向量化阶段耗时从 50.13 s 降至 0.45 s，总重建耗时从 57.53 s 降至 9.83 s，60 题检索结果逐题保持一致。
